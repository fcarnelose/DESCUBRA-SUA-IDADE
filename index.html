Sobre o projeto

O projeto Calculadora de Idade Futura foi desenvolvido utilizando Python. Seu objetivo é calcular a idade de uma pessoa em um ano escolhido pelo usuário.

01

Entrada de dados

O usuário informa seu ano de nascimento.

02

Cálculo

O programa subtrai o nascimento do ano escolhido.

03

Resultado

O programa mostra a idade calculada.

O código em Python

Veja como o programa foi desenvolvido:

nascimento = int(input(
    'Qual o ano de seu nascimento? '))

anoFuturo = int(input(
    'Em qual ano voce quer saber sua idade? '))

idadeFutura = anoFuturo - nascimento

if anoFuturo > 2026:
    print("No ano de", anoFuturo,
          "voce terá", idadeFutura, "anos")
else:
    print("No ano de", anoFuturo,
          "voce fez", idadeFutura, "anos")

Como funciona?

input() – recebe informações do usuário.

int() – transforma o valor em número inteiro.

idadeFutura – armazena o resultado da subtração.

if – verifica se o ano escolhido é maior que 2026.

else – executa quando a condição não é verdadeira.
